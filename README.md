# docker-scpsl

A modified docker file that includes [ffmpeg](https://ffmpeg.org/), and the required libraries to run [my associated egg](https://github.com/esserGaming/scpsl-egg/).

## GitHub package branches:
- master `ghcr.io/essergaming/docker-scpsl:master` **(Experimental branch)**
- heavy `ghcr.io/essergaming/docker-scpsl:heavy` **(Includes ffmpeg & mono)**
- slim `ghcr.io/essergaming/docker-scpsl:slim` **(Does not include ffmpeg, smaller size)**
